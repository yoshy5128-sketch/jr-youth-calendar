Jrユース・スケジュール v7 完全版
===================================

今回の修正:
鍵当番の上下行への誤コピーを防止します。

例:
8/8 川崎マリエン
  鍵当番欄が空欄
その下の7小
  開: 来島
  閉: 中澤

この場合、
川崎マリエンには来島・中澤を入れません。

実装:
1. Geminiへ
   「鍵当番は同じ横一列の右端セルだけを見る」
   「上下の行から絶対に引き継がない」
   と明示。

2. 独立した2回の画像解析結果を比較。

3. keyOpen / keyClose は
   2回の読み取りで同じ氏名が一致した場合だけ採用。

4. 片方だけが氏名を読んだ場合、
   または2回で氏名が食い違った場合は、
   誤登録防止のため空欄にします。

5. 片方の解析にしか存在しない予定行についても、
   予定自体は取りこぼし防止で残しますが
   鍵当番は空欄にします。

この方式は、
「正しい鍵当番を誤って空欄にする」可能性よりも
「別行の氏名を誤登録する」危険を避けることを優先しています。
画面上で空欄は手修正できます。
